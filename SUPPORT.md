# Support

## Where to ask

1. **Discussions** — for questions, ideas, and help using an existing capability. Open a discussion
   on the relevant repository: <https://github.com/orgs/neuron-runtime/discussions>
2. **Issues** — for reproducible bugs and concrete feature requests. Every repository in this
   organization has issue templates; pick the closest match.

Before opening either, search the repository's existing issues and discussions. The question has
usually been asked already.

## What to include

- Which repository and which component: the Neuron Assembly Protocol, N.O.R.E., or a named SDK.
- The language and SDK version you are using.
- A minimal example that shows the problem.

## Security issues

Do not report vulnerabilities here. Follow [SECURITY.md](SECURITY.md) instead.

## Code of conduct concerns

Report conduct concerns privately, not in a public issue. See
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Commercial and integration inquiries

Open a discussion in the organization's Discussions area. Please do not include confidential
information in a public thread.
